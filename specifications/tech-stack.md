# Stack tecnológica

- TypeScript como linguagem principal.
- Next.js para a aplicação web institucional.
- Tailwind CSS para o visual moderno e responsivo.
- SQLite como banco inicial para armazenamento de notícias e dados simples.
- Estrutura de dados mock para cursos e matrizes enquanto a fonte oficial não for integrada.

A stack prioriza confiabilidade, rapidez de desenvolvimento e boa experiência em dispositivos móveis.
